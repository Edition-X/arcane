# Code of Conduct

This project follows the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be respectful, assume good faith, and keep discussion focused on the
work. Harassment, personal attacks and deliberately disruptive behaviour are
not welcome.

Report a problem privately to the maintainer through
[GitHub Security Advisories](https://github.com/Edition-X/arcane/security/advisories/new)
or by opening an issue if it is not sensitive. Reports are handled
confidentially.
